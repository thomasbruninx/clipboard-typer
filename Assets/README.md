# App icon

`AppIcon.png` is the source artwork for Clipboard Typer's bundled macOS icon. Generated with the built-in image generation tool, then refined with that tool for exterior transparency. Native `sips` and `iconutil` resize and package it during builds; no external image dependencies are needed.

## Generation prompt

Use case: stylized-concept

Asset type: production macOS app icon for Clipboard Typer, one square 1024x1024 image.

Primary request: A beautiful Apple-style macOS utility app icon with a keyboard as the sole subject. A softly sculpted compact silver aluminum keyboard, centered and viewed slightly from above, with elegant ivory keycaps, precise subtle key spacing, and one restrained blue accent key. Place it on a rich but restrained cool blue rounded-square macOS icon tile with soft depth, polished bevel, gentle studio highlights and delicate ambient shadow. The keyboard should occupy most of the tile and remain instantly readable at small sizes. Premium native macOS aesthetic, simple silhouette, exceptionally clean professional 3D product illustration, balanced and calm.

Composition: front-facing rounded-square tile centered with approximately 7% transparent margin on all four sides, keyboard centered within the tile; straight horizontal orientation, slight top-down perspective for depth. Full icon fits in frame. Exterior outside the rounded tile must be genuinely transparent, no backdrop.

Constraints: one icon only, no collage, no app mockup, no text, no lettering on keys, no logo, no watermark, no cables, no extra objects. Crisp rounded corners and alpha transparency. Keyboard needs large clear keycaps and a prominent wide spacebar.

## Refinement prompt

Edit this macOS app icon. Preserve the entire keyboard design, silver and ivory materials, blue accent key, blue rounded square, lighting, centering and dimensions. Change only the exterior alpha edge: remove the stray cyan/blue/white wisps above and beside the tile and all stray pixels in the transparent margin. Make the outer rounded-square silhouette pristine and smoothly anti-aliased, with a completely clean transparent exterior and consistent 7% margin. No new elements. Output one square app icon with actual transparency.
